# Match the Attached Video

## Goal
Rework the existing one-page portfolio so its visual rhythm and movement closely follow the attached video, while keeping Bryant’s current content, project images, filters, image enlargement, contact form, and dark mode.

## Visual changes
- Recompose the opening into a tall editorial cover with oversized layered name/type, a stronger portrait crop, compact navigation, and small supporting details.
- Use the video’s deep maroon, warm cream, muted red, and charcoal balance through the existing theme tokens.
- Restructure each section around alternating cream/red numbered panels, large serif headings, compact labels, overlapping project screenshots, and asymmetric editorial spacing.
- Restyle the portfolio as art-directed showcases while preserving all four automation categories and every project.
- Carry the same visual language through experience, testimonials, contact, and footer rather than limiting it to the opening.

## Motion
- Replace the uniform fade-up with directional staggered reveals, clipped text entrances, image scale reveals, and alternating left/right movement.
- Add subtle scroll-linked depth to large background type and selected images, without making text hard to read.
- Use smooth hover zoom, card lift, button press, filter transitions, and an animated image viewer.
- Respect reduced-motion settings and keep all controls keyboard accessible.

## Validation
- Check the full page at desktop and mobile sizes.
- Verify navigation, dark mode, category filters, image enlargement, Escape close, and contact form behavior.
- Confirm there are no overlaps, blank sections, console errors, or unreadable text.

## Technical details
- Keep the existing TanStack one-page structure and content source.
- Implement the visual system in semantic tokens and reusable CSS utilities.
- Extend the current reveal and click-effect components rather than adding a heavy animation dependency.
